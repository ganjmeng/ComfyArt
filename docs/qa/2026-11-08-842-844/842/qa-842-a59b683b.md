## 仓库里的 schema 依据

没有读取 `wavespeed.ai`，也没有调用供应商或价格 API。本 tip 的 diff 不改 fixture。

已提交的 `tests/fixtures/wavespeed_catalog_subset.json` 是仓库里 `openai/gpt-image-2.6-flare/text-to-image` 唯一的 request schema。`properties` 的键是：

`aspect_ratio`，`complexity`，`enable_base64_output`，`enable_sync_mode`，`frame_count`，`frame_duration_ms`，`output_format`，`prompt`，`quality`，`resolution`。

没有 `image`、`images`、`reference`、`refs`。`output_format` 含 `gif`。同 fixture 里 2.6-flare edit 的 `output_format` 不含 `gif`。这段 description 写着 “Medium 1k is $0.05”，是仓库内文案，不是本轮从线上抓的 schema。

`api/wavespeed.py` 的 `build_payload` 只在 schema 有 `images` 或 `image` 时写入参考图。没有这些键时，URL 不会进入最终 body。`api/gif_image.py` 的 `route_gif` 仍把静图放进 `images`，并标 `gif_route=reference_t2i`，然后 `submit` 继续走生成。

## 静图 → GIF 的最终 payload 与零 POST 断言

新断言范围：`tests/_qa842_a59b_independent.py::test_new_still_gif_must_refuse_and_send_zero_generation_posts`。确认阈值设为 1000，避免 409 被当成拒绝。输入是编辑 feature、静图 URL、`output_format=gif`、`frame_count=99`。

断言要求：非 409 的可读不支持错误，且生成 POST 列表为空。

实际失败（`GATE=1`，exit 1）：

```text
exception=None
gen_count=1
url=https://api.wavespeed.ai/api/v3/openai/gpt-image-2.6-flare/text-to-image
body={'output_format': 'gif', 'frame_count': 16, 'frame_duration_ms': 200, 'prompt': '把这张做成动图'}
still_in_body=False
quote_model=openai/gpt-image-2.6-flare/text-to-image
quote_route=reference_t2i
quote_frames=16
quote_tier='1k · GIF · 16f · 200ms'
```

估价 `gif_note` 有可读说明（「这张静图的地址不会送进请求」/ “this still's URL is not sent”），模型没有退回 2.5，也没有改走视频。生成 POST 仍然发出，body 里没有静图 URL。`src/actions.ts` 的 `toGif` 仍把 `image` 和 `images` 放进任务。

作者测试 `test_committed_fixture_matches_official_t2i_fields_and_post_drops_still_url` 把「URL 不在 body 里且 submit 成功」写成通过条件。那条通过不等于本验收的零 POST。
