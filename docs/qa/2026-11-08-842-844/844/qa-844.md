用例要求格式无效则明确拒绝、不假下载。实现把「解析失败但文本里看不出危险标记」当成安全文件的预览失败。这和 S05 的产品选择叠在一起，S04 不能按原用例通过。

### S05 安全文件仅预览失败仍可下载 — PASS

`text_only.svg`：`preview_failed` / `undrawable`，下载等于原文，失败预览是 PNG（左上黑点、其余灰），不是 SVG URL。`test_safe_undrawable_preview_failure_still_downloads` 与 `test_thumb_rejects_script_and_download_keeps_safe_failure`。探针再读下载响应：200，`Content-Type: image/svg+xml`，`Content-Disposition` 以 `attachment;` 开头，`Content-Security-Policy: sandbox; default-src 'none'`，`X-Content-Type-Options: nosniff`，`Cache-Control: no-store`，正文 SHA-256 等于原文。缩略图是 `image/png`，正文以 PNG 魔数开头且不含 `<svg`。

`src/svgFile.ts` 的 `inlineSvg` 固定为 `false`。没有 `svg_preview` 时画布走 `/comfyart/thumb`，不把 `.svg` 的 `/api/view` 当图片源。`vectorize.ts` 失败回退是 `RASTER_FAIL_PNG`（`data:image/png`），不是 SVG URL。`test_frontend_svg_preview_is_not_an_svg_url` 在命令 2 里实际跑过（53 passed 且 0 skipped）。危险文件不会走进这条「仍可下载」：脚本夹具 `download is None`。

### S06 大小 / 像素 / 复杂度 / 时长 — HOLD

生产阈值在 `LIMITS`，`admit(data)` 不接收自定义上限。`test_limits_are_the_production_caps` 与 `docs/qa/826/SECURITY.md` 一致：512 KiB、边长 1024、面积 1024×1024、元素 2000、0.25 秒。比较符是 `>`，等于阈值放行。

探针实测：

| 边界 | 结果 |
| --- | --- |
| 边长 1024×1 | `normal`，PNG 尺寸 (1024, 1) |
| 面积 1024×1024 | `normal`，PNG (1024, 1024) |
| 边长 1025 与 1024×1025 | `too_many_pixels`，此后 `Image.new` 次数不增加 |
| 字节数 = 512 KiB 的非 XML | `malformed` 且可下载（还没到 `too_large`） |
| 字节数 = 512 KiB + 1 | `too_large`，不下载；作者测试还证明不调用解析器 |

| 元素数 = 2001 | `too_many_elements`，不下载 |

### S07 下载与内联分离 — HOLD

安全文件的响应头和「画布不内联」已由 S05 的探针和 `test_frontend_svg_preview_is_not_an_svg_url` 覆盖。`api/thumbs.py` 不再把 SVG 当 `image/svg+xml` 返回，拒绝时 404，否则返回 PNG，CSP 为 `sandbox; default-src 'none'`。脚本夹具不能从 `/comfyart/svg_download` 拿回原文。

不能过的部分：S02 漏掉的外链文件会被当成 `normal`，下载路由返回原始 SVG 附件。attachment 不能代替安全闸。`Content-Type` 仍是 `image/svg+xml`，保存后在外部打开不在本卡保证范围内；固定 SHA 也没有对此做浏览器打开实验。

### S08 允许列表 — HOLD

没有 Tech 签字的正面允许列表。实测拒绝：`foreignObject`、`<animate>`、`<image href=data:>`、脚本、事件、`javascript:`。`_SCRIPT_TAGS`、`_RESOURCE_TAGS`、`_ACTIVE_TAGS` 是拒绝表，不是允许表。不在表内的 `<path>`、`<text>`、无 URL 的 `<style>`、`xml-stylesheet`、`fill="url(https:…)"` 都不会因此被拒绝。合法 XML 不等于安全。未定项按测试设计不能宣告通过。

## 隔离：有什么证据，缺什么

有执行证据，不是只看没有弹窗：

- 进程内替换 `socket.socket` 与 `socket.create_connection`：`normal`、`external`、漏网的 stylesheet / fill-url 在 `admit` 期间调用次数为 0
- 同一窗口替换 `open` / `os.open`：上述输入以及 `local_file.svg` 次数为 0；UTF-8 外部实体没有打开 marker 文件
- `entity.svg` 不调用 `ET.fromstring`；超大文件在解析前拒绝；`huge_pixels.svg` 与超限元素数不调用 `Image.new`（作者测试 + 探针）
- `GATE=1` 下命令 2–5、8 全部跑完。作者三组没有因为出站被拦而失败
- 源码扫描禁止 `svg_image.py` 出现 `eval` / `exec` / socket / urllib / subprocess / urlopen

这仍不是生产隔离审计：

- `svg_image.audit()` 是手写字典，不记录某次请求是否试图出站、读文件或展开实体
- 没有 seccomp、网络命名空间、或禁用 DTD 的解析器配置。实体防护是原始字节子串
- `wavespeed.py` 本身有 `urllib.request` 与 `aiohttp`（供应商下载）。SVG 模块没引用它们，不能写成「整个进程不能联网」
- 漏分类的外链虽然这次没打开 socket，文件仍可下载

因此：**夹具探针可以引用；不能写成隔离审计已完成。** 缺的那一层保持 HOLD，不因为探针没弹窗就升成 PASS。
