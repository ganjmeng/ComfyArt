# #673 C 组金图核对 + 尺寸（本地，未推送）

| 技能 | 映射核对 | 理由 |
|---|---|---|
| naive-illustration | MATCH | 金图 ex01 就是弹框里的飞行员猫，封面和 ex02–04 也都对得上 |
| logo-abstract | MATCH | 金图 ex02 = 徽派屋顶 + JIANYUE；另有 EGRET、东方明珠、紫禁城等，与弹框缩略图条一致 |
| photo-split-poster | MISMATCH | 下载的 16 张是「上实拍/下插画」的拼贴（Berry Pancakes 等），没有「丰收是一封写给土地的家书」那张海报；与我们的图差异 46–54。搜到的大概率是另一张卡，需要重抓 |
| ppt-visual | MATCH（有保留） | ex01 1920×10470 是暗调山海长图，与弹框一致；金图封面「PREMIUM SLIDES」与我们的封面是同一张（差异 6.6） |
| promo-ecommerce | MATCH（例图）/ UNSURE（封面） | ex01 是秋日新章六宫格（LENO/LUMVEX）；ex02 是价签贴纸；金图封面是黑白人像拼贴，弹框截图里看不到封面，没法核对 |

## 关键发现
- naive-illustration、logo-abstract、ppt 封面、promo ex04 与金图的差异 <3：**不是洗过的图，是金图原样缩小**（连 JIANYUE、飞行员猫、LENO/LUMVEX 都在）。#636 的 soft wash 在这几张上等于没洗。
- 我们所有的图都比金图分辨率低（金图 1254–2560px，我们 768–1360px；logo 例图只有 8–21KB）。
- photo-split-poster 的金图要重抓。
