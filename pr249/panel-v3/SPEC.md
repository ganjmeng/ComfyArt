# #249 多角度面板 v3（仅 mock）
## 主体 vs 摄像头
- 主体：相机不动，转物体（= main 的「对象」视图）。摄像头：物体不动，相机绕球面走（= main 的「相机」视图）。
- 两个 tab 驱动同一组参数（h/v/z），切换时数值不变，读数也一样。
## 方块补上的细节（全部自己画）
面标记（右/左/背/顶/底 + 顶/底面指向正面的蓝色箭头）；正面贴原图 + 光泽高光 + 蓝色描边；圆角面 + 接缝 + 按光照分面明暗；地面网格 + 虚线轨道圈；投影阴影；拖动把手（水平弧线 + 垂直弧线）；实时角度读数；四角度时轨道上 4 个蓝点。
球：经纬线（背面虚线），赤道和当前经线高亮；原图居中；相机把手（镜头、按深度缩放、蓝色光晕、虚线连到中心、^ v < > 箭头）；地面阴影。
## 映射
| 控件 | 当前 main | v3 | 模型参数 |
|---|---|---|---|
| 旋转 | 水平 0–360 | ±180，每 45° 吸附 | horizontal_angle=(v+360)%360 |
| 倾斜 | 垂直 −30..60 | −30/0/30/60 | vertical_angle |
| 缩放 | 远近 0–10 连续 | 特写/中景/远景 | distance 0/1/2 |
| 预设 | 正面/左前/右前/左侧/右侧/背面 | 同左 | horizontal_angle 0/315/45/270/90/180 |
| 四角度 | 立即提交 | 选中态，锁定 ×4 | 4 个请求，h=270/315/45/90 |
| ×N | 无 | 1–4 | N 个参数相同的请求 |
