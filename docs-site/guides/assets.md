# Assets

## My Assets

![My Assets panel](/images/assets.webp)

**My Assets** (top bar) holds two kinds of things:

::: tip WaveSpeed Key and cost
Generating with a brand kit, character or product: these run on WaveSpeed cloud models, so they need a [WaveSpeed Key](/guides/wavespeed-key). The estimated cost is shown next to **Send** (or on the button) before anything runs, and jobs of $0.50 or more ask you to confirm. See [Models and costs](/guides/models).
:::

- **Files**: every image and video you generated or uploaded, filtered by Generate or Upload, with search. Thumbnails load as you scroll.
- **Brand Kit, Character, Product, Custom**: named assets you create. Select something on the canvas and add it to one of these groups, then reference it in a prompt with `@`.

Click any item to place it on the canvas.

## Brand kits

A brand kit collects written guidelines, logos, named color roles, fonts and reference files. **New Brand Kit** in My Assets, or clicking a kit, opens the full-page kit editor; every change saves automatically.

![Brand kit editor](/images/brand-kit-editor.webp)

- **Drag files here or click to upload** adds brand files to the kit's references; **Extract from file** has the Agent read a brand guide (image or PDF) and fill in the kit.
- **Design Guidelines**: plain-text rules the Agent follows.
- **Logo**, **Color** (each color gets a role such as primary or background) and **Fonts**. Add a font from the [font picker](/guides/design#fonts) or upload font files; uploaded fonts can be used for canvas text everywhere.
- **Create a project with this kit** starts a new project linked to it. A kit can also be the default for new projects, duplicated, or given a cover.

Link a kit to an existing project from the project menu (**Project Brand Kit**). The Agent receives the linked kit with every message.

## Reference board

The **Reference** panel (top bar) collects reference images for a project: upload them, pick them from My Assets, or add images selected on the canvas. Filter by source (upload, canvas, library), sort by newest or name, and open, rename, copy, cut, duplicate, export or delete them.

Each reference has **Style Analysis** and **Composition Analysis** (run by the Agent, the notes can go straight into your prompt) and **Generate Variations**. **Generate moodboard** lays the references out in a frame.
