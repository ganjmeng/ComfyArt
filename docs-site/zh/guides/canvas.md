# 画布

画布是基于 [tldraw](https://tldraw.dev) 的无限白板。你做出来的所有东西（图片、视频、音频、文字、形状、画板、网页、3D 模型）都放在上面，而且始终可以再编辑。

![ComfyArt 左侧是 Agent 面板，画布上是一个画板](/images/agent-result.webp)

## 界面布局

::: tip WaveSpeed Key 与费用
评论直接执行和点选修改走 WaveSpeed 云端模型，需要配置 [WaveSpeed Key](/zh/guides/wavespeed-key)，运行前会在 **发送** 旁（或按钮上）显示预估费用；预估 $0.50 及以上会先请你确认。见[模型与费用](/zh/guides/models)。
:::

- **左侧**：[Agent](/zh/guides/agent) 面板。可以在设置菜单里移到右边，也可以最大化或收起。
- **顶部**：项目菜单和项目名、**参考** 和 **我的素材**、页面标签（双击标签可以重命名）、**导出**、全部评论和设置。
- **底部**：工具（选择、评论、涂鸦、插入）和生成按钮，按钮旁的箭头可以在图像、视频和音频生成之间切换。
- **右下角**：背景色、图层、生成文件、小地图和缩放。

## 形状与内容

- **文字和形状**：富文本、任意字体、渐变和图片填充、钢笔工具和布尔运算。见[文字、形状与路径](/zh/guides/design)。
- **涂鸦**：任意颜色和粗细；插入菜单里还有便签。
- **上传**：可以拖入图片、视频、音频、PDF（每页变成一张图，放在一个画板里）、Lottie 动画、3D 模型（GLB、GLTF、OBJ、FBX、STL、PLY）和 HTML 小组件。

多选时会出现工具栏：自动整理、编组、合并图层、用 **布尔运算** 组合形状、对齐、分布和下载（包括导出 PSD）。

![多选工具栏](/images/multi-select.webp)

右键菜单包括剪贴板、层级、编组、翻转、锁定、替换、发送到生成器、批量重命名和导出。

## 画板

画板用来按精确尺寸承载一份设计。选中画板会出现它的工具栏：

![Spring menu 画板上方的画板工具栏](/images/frame-toolbar.webp)

- **名称**、宽和高（每一项都可以 **固定** 或随内容自适应），以及 **锁定宽高比**。
- **尺寸预设**：Instagram、Instagram 竖版、快拍 / 抖音、YouTube 封面、演示文稿 16:9、桌面网页、手机、A4 和 A4 横版。
- **填充、描边和圆角**：画板的背景色、边框和圆角半径。
- **自动** 布局会在子元素变化时重新排列；**手动** 则保持你摆放的位置。**适应内容** 会把画板缩到刚好包住内容。
- 直接往画板里 **生成**，对[编辑元素](/zh/guides/elements-mockups)得到的画板 **重新渲染**，全屏幻灯片播放画板，打包 ZIP 下载或导出。

![画板尺寸预设](/images/size-presets.webp)

## 图层

**图层** 面板列出当前页面的所有内容。最近的结果放在顶部的 **历史记录** 条里。

![画布旁的图层面板](/images/layers-panel.webp)

- 拖动行可以调整顺序，或把形状移进、移出画板。
- 双击名称可以重命名；画板和编组可以折叠或展开。
- 单击选中，Ctrl + 单击加选，Shift + 单击连续选择。
- 每一行都有隐藏和锁定开关。

图层拆分的结果（见[图像工具](/zh/guides/image-tools)）和编辑元素的结果会以一个画板的形式出现在这里，每层一行。

## 评论

用 **评论** 工具在画布上钉反馈：点一个位置，或用套索、方框圈出一块区域。图片上的评论可以直接作为修改去执行，也可以发送到对话里，Agent 会收到这张图和你圈出的准确区域。评论面板列出所有评论，可以按未完成 / 已完成筛选，也可以把评论加到对话里，或一次全部执行。

**点选修改**：按住 Ctrl 点击图片（或悬停后按 C）标记一个物体，然后描述要怎么改。Shift + 点击可以再加标记点。

## 历史与导出

- 项目自动保存。项目菜单里的 **画布历史** 会保留快照，可以随时恢复。
- 选中内容或整页都可以导出为任意倍率的 PNG、JPG 或 PDF，也能导出 **PPTX**：每个画板或每页一张幻灯片，可以选纯图片，或者文字（包括混合样式）、图片和形状都可编辑。
- 同一个项目在另一个标签页里也打开时，ComfyArt 会提醒你，并让旧标签页停止保存，避免覆盖更新的内容。
