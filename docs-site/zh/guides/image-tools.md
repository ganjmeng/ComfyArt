# 图像工具

选中一张图就会出现它的工具栏。**快捷编辑**、**放大**、**去背景** 和 **橡皮工具** 直接放在栏上，其余的在 **⋯** 里。菜单最下面的 **自定义工具栏** 可以选择把哪些工具固定在栏上、是否显示工具名称。

![图片工具栏和更多菜单](/images/image-toolbar.webp)

**编辑元素** 和 **样机** 有单独的页面：[编辑元素与样机](/zh/guides/elements-mockups)；**转 3D** 见[音频与 3D](/zh/guides/audio-3d)。

::: tip WaveSpeed Key 与费用
需要跑模型的工具都走 WaveSpeed 云端模型，需要配置 [WaveSpeed Key](/zh/guides/wavespeed-key)，运行前会在 **发送** 旁（或按钮上）显示预估费用；预估 $0.50 及以上会先请你确认。见[模型与费用](/zh/guides/models)。
:::

需要跑模型的工具会把结果放在原图旁边，并显示进度环，不会覆盖原图。**恢复原图** 可以找回一张图的最初版本。

## 编辑

| 工具 | 作用 |
|---|---|
| **快捷编辑**（Tab） | 用文字描述要怎么改。 |
| **编辑文字** | 自动识别图里的文字，每一行放进一个可编辑的输入框；改哪行就重画哪行，字体、颜色和位置保持不变。没识别到文字时，可以手动填写原文字和新文字。 |
| **局部重绘** | 用画笔、橡皮、套索、框选或智能选择（WaveSpeed SAM3）选出区域，可以反选、羽化，再描述那里要画什么。可选风格：真实、写实摄影、二次元、插画、3D、游戏原画或沿用原图。 |
| **风格迁移** | 用风格预设或一张参考图换风格。 |
| **移动对象** | 选中一个物体拖到新位置，原来的位置会自动补全。 |
| **多角度** | 换个机位重新渲染主体：预设（正面、左侧、右侧、背面、俯视、仰视、特写、中等、广角）或滑块，也可以一次生成 4 个角度。 |
| **扩展** | 按预设比例（原始比例、正方形、横版、竖版、帖子、快拍、封面照片、头像、封面图）或按倍数扩图，可加提示词。 |

## 清理与调整

| 工具 | 作用 |
|---|---|
| **去背景** | 用 BiRefNet 抠出主体。 |
| **橡皮工具** | 涂掉某样东西，WaveSpeed 擦除模型自动补全。 |
| **涂抹** | 用画笔推动像素。 |
| **裁剪** | 拖动控制点或直接输入像素尺寸，附带各平台的比例预设。 |
| **翻转与旋转** | 水平或垂直翻转、旋转 90°，在浏览器里即时完成。 |
| **调整** | 光线、颜色、细节和效果（见下文）。 |
| **效果** | 不透明度、阴影和模糊。 |

画笔类工具（橡皮、局部重绘、涂抹）会在鼠标下显示一个圆圈，大小就是笔刷大小。

### 裁剪

![带比例预设的裁剪栏](/images/crop-bar.webp)

裁剪时，裁剪栏会替换掉工具栏。选择 **自由**、**原始比例** 或预设比例（Instagram 用 1:1 和 4:5，小红书 3:4，快拍和抖音 9:16，YouTube 16:9，Pinterest 2:3，3:2，Facebook 和 X 用 1.91:1），也可以直接输入宽高像素。**重置** 回到完整图片，**完成** 应用裁剪。

### 调整

![海报旁的调整面板](/images/adjust-panel.webp)

四个标签页：**光线**（曝光、对比度、高光、阴影、白色、黑色）、**颜色**（饱和度、自然饱和度、色温、色调）、**细节**（清晰度、锐化、颗粒）和 **效果**（晕影、辉光、柔光）。**自动** 会帮你选好数值；按住 **按住对比** 可以看原图。

调整是无损的。ComfyArt 会保留原始像素和你的滑块数值，所以再次打开调整时会接着上次的状态，而不是在上面再叠一层调整。先 **重置** 再 **应用** 就能恢复未调整的像素；裁剪和翻转仍会保留。

## 放大

放大 2 倍或 4 倍。**忠于原图** 用 4x-UltraSharp；**增强细节** 会在大尺寸下重新绘制，可选风格预设和细节强度，补出新的细节。

## 图层拆分

**图层拆分** 把一张图拆成画板里的可编辑图层，最下面是背景层：

- **自动拆分**：跑 WaveSpeed 的图层拆分模型，保留有用的图层。
- **自定义拆分**：画出任意个框，WaveSpeed SAM3 抠出每个框里的物体。
- **拆出区域**：对任何图层都能用，包括拆分后两样东西还混在一起的图层。框住要拆出的部分，可以拖动边框调整，那部分就会变成独立图层，并自动裁到可见像素边界。即时完成，不跑模型。

拆分后的背景是原图抠掉所有拆出图层的区域再补全，所以移动或隐藏某一层时，下面露出的是干净的背景，不会出现重复内容。

## 文字、矢量与信息

- **提取文字**：复制图里的文字（用 WaveSpeed `paddle-ocr` 或 Agent 识别）。
- **矢量化**：把图描成 SVG。画布上会按当前缩放显示渲染好的位图，保证流畅；下载和导出仍是完整的 SVG。
- **生成信息**：查看提示词、模型和参数；旁边还有 **复制提示词**、**照此再画**（同一提示词换个种子）和 **重新生成**。
- **放大查看** 打开预览大图；**导出** 保存为 PNG、JPG 或 PDF。
