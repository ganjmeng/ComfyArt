文字和形状在画布上始终是可编辑的矢量；导出可编辑对象的 PPTX 时，它们仍是文字和形状。

## 富文本

双击文字进入编辑。里面什么都没选时，文字工具栏改的是整段文字；选中几个字后，颜色、字体、字重、字号、**B**、*I* 和 <u>U</u> 按钮只作用于选中的部分，所以一段文字可以混合多种样式。

<Frame>
  <img src="/images/ours/zh/rich-text.webp" alt="文字工具栏给选中的短语设置加粗和颜色" />
</Frame>

工具栏里还有对齐、行距和字距、描边、大小写和修饰。导出 PPTX 时，混合样式会保留为分开的文本段。

## 字体

字体菜单可以搜索所有可用字体，分为 **品牌套件**（上传到品牌套件里的字体）、**常用** 和 **本机**（本机字体，浏览器会先请求权限）三组。每个字体名都用它自己的字形显示。

## 形状与填充

**插入** 可以添加矩形、椭圆、多边形、星形、直线和箭头。选中形状，在它的工具栏里打开 **填充**：

<Frame>
  <img src="/images/ours/zh/fill-editor.webp" alt="填充编辑器，径向渐变" />
</Frame>

- **纯色**、**线性**、**径向** 或 **图片** 填充。
- 渐变可以有任意多个色标。每个色标有位置和带透明度的颜色，所以渐变可以淡出（比如上图里柔和的太阳）。线性渐变可以设角度。
- **混合模式**（正片叠底、滤色、叠加等 CSS 混合模式）让形状和下面的内容混合。

描边可以在内侧、居中或外侧，实线、虚线或点线。矩形可以设圆角。

## 钢笔与节点编辑

按 **P**（或从 **插入** 里选钢笔）绘制路径：单击添加角点，拖动拉出曲线手柄，单击第一个点闭合形状；双击、按 Enter 或 Esc 结束一条开放路径。

双击路径编辑它的节点。拖动点可以移动它，拖动手柄可以弯曲曲线。布尔运算的结果也是路径。

  <img src="/images/ours/zh/pen-nodes.webp" alt="编辑一片叶子路径的节点" />

## 布尔运算

选中两个或更多形状，在选择工具栏里打开 **布尔运算**：**合并**、**减去顶层**、**相交** 或 **排除重叠**。结果是一条新的路径，沿用最底层形状的样式；**减去顶层** 会从最底层形状里挖掉上面的形状。
