## 编辑元素

**编辑元素** 把一张成品图（海报、广告、设计截图）重建成可编辑的画板：

1. 用 WaveSpeed 的 `paddle-ocr` 模型识别每一行文字，生成位置、大小、颜色和对齐方式都一致的真实文字图层。打开 [Agent](/zh/guides/agent) 时，还会匹配每行字的字体风格和字重；没开 Agent 时一律用 Arial。
2. 用 WaveSpeed 的 SAM3 分割模型把主体产品和 Logo 抠成单独的图片图层。
3. 用 WaveSpeed 的擦除模型把文字和物体从画面里擦掉，留下干净的背景图层。

新画板会出现在原图旁边。改文案、字体或颜色，挪动产品，然后点画板工具栏里的 **重新渲染**，把编辑过的图层融合回一张自然的图片。

<Note>
编辑元素不需要本地依赖或模型：文字识别、抠图和擦除都走 WaveSpeed。见[模型与费用](/zh/guides/models)。
</Note>
## 排版画板

排版画板是一种画板：你先手动排好版，再把它渲染成一张完成的图。选 **插入 → 排版画板**，然后往上面放任何东西：文字、形状、图片、涂鸦，以及两种画板专用元素：

- **AI 内容块**：一块带描述的虚线区域（比如「大理石桌上一杯冒着热气的拿铁」）。双击写描述。渲染时会在这块区域里生成和整体设计协调的新内容。
- **二维码**：双击输入链接，渲染后依然清晰。

点画板工具栏里的 **渲染**。ComfyArt 会导出画板，把每个 AI 内容块标成灰色区域，让图像模型把版式变成完整的设计，同时保留你的文字、Logo 和照片的位置。结果放在画板旁边。

**渲染** 旁边的列表按钮里有：

- **上次渲染后的改动**：新增、修改或删除了哪些元素。
- **渲染会发送的内容**：真正发出的提示词，包括每个 AI 内容块的位置和描述，渲染之前就能检查。
- **导出版式**：把画板存成 `.layout.json` 文件。用 **插入 → 导入版式** 可以在当前或其他项目里还原，当作模板重复使用。

编辑元素生成的画板也是排版画板，那里的按钮叫 **重新渲染**。

## 样机

**样机** 把一张产品照片（T 恤、马克杯、包、盒子、手机）变成可以印设计的表面。ComfyArt 只需测一次照片的深度、抠一次产品；之后摆放设计是即时的，在浏览器里完成。

<Frame>
  <img src="/images/ours/zh/mockup-panel.webp" alt="样机面板把圆形徽章 Logo 放到马克杯上" />
</Frame>

样机面板里：

- **设计稿**：从画布上选任意一张图。透明背景的 Logo 效果最好；需要的话先跑一次 **去背景**。
- **左右**、**上下**、**大小** 和 **角度** 用来摆放设计。
- **贴合表面** 让设计随产品的褶皱和曲面弯曲。产品自身的明暗会叠在设计上，产品以外的部分会被遮掉。
- **转为图片** 把样机拼合成一张普通图片。
- **AI 融合** 用图像模型重新渲染结果，让布料、印刷质感和光照更真实。

样机始终可编辑：再次选中它就能换设计或挪位置。
