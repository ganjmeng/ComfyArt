## 首页

打开 [http://127.0.0.1:8188/comfyart/](http://127.0.0.1:8188/comfyart/) 就会进入首页。

<Frame>
  <img src="/images/ours/zh/home.webp" alt="Loomi 首页" />
</Frame>

- **你想设计什么？**：输入需求并发送，Loomi 会新建一个项目，把需求交给 [Agent](/zh/guides/agent)。用 **+** 或把图片拖到输入框里附加图片，或者把模式切到图像、视频，直接生成。
- **帮你做：**：快捷入口（社交媒体、电商、品牌、创意、网站）会帮你填好提示词的前半句。
- **最近项目** 显示你最近的画布；**查看全部** 打开项目库。
- **从 Skill 开始** 列出内置技能和你自己的技能（标着「我的」）。选一个就会新建一个带上该技能的项目。

<Tip>
**WaveSpeed Key 与费用**

从一句话或技能开始设计时走 WaveSpeed 云端模型，需要配置 [WaveSpeed Key](/zh/guides/wavespeed-key)，运行前会在 **发送** 旁（或按钮上）显示预估费用；预估 $0.50 及以上会先请你确认。见[模型与费用](/zh/guides/models)。
</Tip>
左侧栏有 **新建项目**、**首页**、**项目库** 和设置菜单。

## 项目

<Frame>
  <img src="/images/ours/zh/projects.webp" alt="项目库" />
</Frame>

项目库列出所有项目，并显示画布预览。卡片菜单里可以 **置顶**、重命名、**创建副本**（对话不复制）或删除。也可以用 **选择** 勾选多个（或 **全选**）一起删除。删除项目会删掉它的画布、对话和保存的版本；生成的文件仍留在 ComfyUI 的输出目录里。

每个项目对应一个网址 `/comfyart/?project=<id>`，连同快照历史一起保存在 Loomi 的 SQLite 数据库（`user/__comfyart/data.db`）里。旧版本的项目是 `comfyart/projects/` 下的 JSON 文件，更新后第一次打开 Loomi 时会自动导入，原文件留在原处不动。打开一个不存在的项目链接（已删除或写错）会显示 **找不到这个项目**，并提供去项目库和新建项目的按钮，不会再打开一张空画布。

## 项目内

在项目里点左上角的 Logo 打开项目菜单。

<Frame>
  <img src="/images/ours/zh/project-menu.webp" alt="项目菜单" />
</Frame>

这里可以回到首页或项目库，新建、复制或删除项目，打开 **画布历史**（恢复快照），导入图片，执行撤销、创建副本和缩放命令，打开 Agent 的 **记忆**，以及给项目关联 **项目品牌套件**。每条发给 Agent 的消息都会带上关联的套件。

项目会在每次改动后约一秒自动保存。项目名旁边显示 **保存中…** 或 **已保存**（鼠标悬停可看时间）。保存失败时会变成 **保存失败 · 重试**，点一下就会重新保存。还有改动没保存完就关闭标签页时，会先提示确认。

## 设置

齿轮按钮（项目里在右上角，首页在左下角）打开设置菜单。

<Frame>
  <img src="/images/ours/zh/settings-menu.webp" alt="设置菜单" />
</Frame>

| 设置 | 选项 |
|---|---|
| 语言 | 中文或 English，即时切换 |
| 主题 | 浅色、深色或跟随系统 |
| WaveSpeed API key | 添加或更换 [WaveSpeed Key](/zh/guides/wavespeed-key) |
| 使用指南 | 按当前界面语言打开本文档站 |
| 对话区位置 | Agent 面板放在左侧或右侧 |
| 快捷键 | 完整的快捷键列表（也可以按 `?` 打开） |
| 页面在后台时推送系统通知 | 标签页在后台时任务完成，会弹浏览器通知 |
