# 资产

## 我的素材

![我的素材面板](/images/assets.webp)

顶部栏的 **我的素材** 里有两类东西：

::: tip WaveSpeed Key 与费用
用品牌套件、角色或产品生成时走 WaveSpeed 云端模型，需要配置 [WaveSpeed Key](/zh/guides/wavespeed-key)，运行前会在 **发送** 旁（或按钮上）显示预估费用；预估 $0.50 及以上会先请你确认。见[模型与费用](/zh/guides/models)。
:::

- **文件**：你生成和上传的所有图片和视频，可以按「生成」或「上传」筛选，也可以搜索。缩略图随滚动加载。
- **品牌套件、角色、产品、自定义**：你自己建的具名素材。在画布上选中内容，加到其中一组，就能在提示词里用 `@` 引用。

点任意一项就会把它放到画布上。

## 品牌套件

品牌套件收集文字规范、Logo、具名的颜色角色、字体和参考文件。在我的素材里点 **新建品牌套件**，或点开某个套件，就会打开整页的套件编辑器；所有改动都会自动保存。

![品牌套件编辑器](/images/brand-kit-editor.webp)

- **拖拽或点击上传文件** 把品牌文件加进套件的参考图；**从文件中提取** 让 Agent 读一份品牌手册（图片或 PDF）并填好套件。
- **设计指南**：Agent 会遵守的纯文本规范。
- **Logo**、**颜色**（每个颜色都有一个角色，比如主色或背景色）和 **字体**。可以从[字体选择器](/zh/guides/design)添加字体，或上传字体文件；上传的字体在所有画布文字里都能用。
- **使用此素材创建项目** 新建一个关联该套件的项目。套件也可以设为新项目的默认套件、创建副本或设置封面。

在项目菜单的 **项目品牌套件** 里可以给现有项目关联套件。每条发给 Agent 的消息都会带上关联的套件。

## 参考板

顶部栏的 **参考** 面板用来收集项目的参考图：可以上传，从我的素材里挑，或者把画布上选中的图加进来。可以按来源（上传、画布、素材库）筛选，按最新或名称排序，并打开、重命名、复制、剪切、创建副本、导出或删除。

每张参考图都有 **风格分析** 和 **构图分析**（由 Agent 完成，分析结果可以直接加进提示词），以及 **生成变体**。**生成情绪板** 会把参考图排进一个画板。
